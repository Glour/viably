## 1. Проблема

Текущая экономика Viably построена на фиксированной стоимости: **1 кредит = 1 сообщение, 10 кредитов = генерация**. Но с переходом на **агентный цикл** (agent loop до 50 итераций, до 500K токенов на запрос) реальные затраты на API стали сильно варьироваться — от $0.01 за простой ответ до $2+ за сложную агентную генерацию. Фиксированная цена больше не отражает реальность.

**Ключевые проблемы:**
1. **Убыточность на сложных запросах** — агентный цикл может стоить нам $1-3 за один запрос, но пользователь платит 1 кредит (~$0.10)
2. **Перекрёстное субсидирование** — простые вопросы и сложные генерации стоят одинаково
3. **Нет лимита деплоев** — каждый задеплоенный проект жрёт ресурсы VPS, а лимит сейчас только на количество проектов
4. **Тяжёлые промпты на каждый запрос** — 13-25 KB системного промпта (до 15K input tokens) отправляется даже для простого вопроса «что делает строка 42?»
5. **Нет прозрачности** — пользователь не понимает, почему кредиты тратятся

## 6. Оптимизация API-затрат (чеклист)

### 6.1 Умный роутинг промптов (КРИТИЧНО)

Сейчас `ai_service.py:470-507` — ОДИН путь для всех запросов. Полный системный промпт (BASE 10KB + CATEGORY 33KB + TEMPLATE + BOILERPLATE) всегда отправляется.

**Что нужно:**

| Тип запроса | Промпт | Модель | Экономия |
|---|---|---|---|
| Простой вопрос / FAQ | BASE_LITE (3 KB) | **Haiku 4.5** | **-85% vs текущего** |
| Правка стилей / мелкий фикс | BASE + artifacts context | **Sonnet 4.6** | **-40%** (без category) |
| Генерация / сложная правка | FULL (base + category + template) | **Sonnet 4.6** | 0% (как есть) |
| Первая генерация | FULL + BOILERPLATE | **Sonnet 4.6** | 0% |

**Логика определения типа** (добавить в `ai_service.py:414`):

```python
def _detect_complexity(user_content: str, has_artifacts: bool) -> str:
    # Simple: вопрос без кода, FAQ, объяснение
    if len(user_content) < 200 and not any(kw in user_content.lower()
        for kw in ["создай", "добав", "измени", "сделай", "перепиши", "генер"]):
        return "simple"

    # Moderate: мелкие правки
    if any(kw in user_content.lower()
        for kw in ["цвет", "текст", "размер", "шрифт", "стиль", "margin", "padding"]):
        return "moderate"

    return "complex"
```

**Экономия на 100 запросов:**
- Сейчас: 100 × $0.05 (промпт) + $0.05 (ответ) = **$10.00**
- С роутингом: 40 simple × $0.005 + 30 moderate × $0.03 + 30 complex × $0.10 = **$4.10**
- **Экономия: -59%**

### 6.2 Prompt Caching (КРИТИЧНО)

Сейчас в `anthropic/client.py:94-100` — только `ephemeral` cache (5 мин). Системный промпт 13-33 KB (4K-10K tokens) оплачивается полностью каждый раз.

**Что нужно:**

Разбить system prompt на 2 части:
1. **Статическая часть** (BASE + CATEGORY) — кешируется, ~10K tokens → cache read = $0.003 вместо $0.03
2. **Динамическая часть** (artifacts context) — не кешируется

```python
system_param = [
    {
        "type": "text",
        "text": base_and_category,  # Статика — всегда одинаковая
        "cache_control": {"type": "ephemeral"}  # Будет кеширована
    },
    {
        "type": "text",
        "text": template_and_context  # Динамика — меняется
    }
]
```

Anthropic ephemeral cache уже работает, но **нужно разделить промпт на стабильную и нестабильную части**, чтобы cache hit rate вырос с ~10% до ~80%.

**Экономия: -30-40% на input tokens.**

### 6.3 Batch API (-50%) — для фоновых задач

[Anthropic Batch API](https://platform.claude.com/docs/en/build-with-claude/batch-processing):
- **-50%** на input и output tokens
- Обработка в течение 24 часов (обычно < 1 час)
- Стакается с prompt caching

**Где применить:**
- Валидация кода (validation gate после генерации)
- Генерация README / описаний проектов
- Предварительный анализ кода (plan generation)

**НЕ применимо для:** streaming-ответов в чат (нужен real-time).

**Экономия: -50% на фоновых задачах (оценка ~15-20% от всех запросов).**

## 7. Новая экономическая модель

### 7.1 Формула динамического расчёта кредитов

```python
def calculate_credit_cost(input_tokens: int, output_tokens: int) -> int:
    weighted_tokens = input_tokens + (output_tokens * 3)
    credits = max(1, math.ceil(weighted_tokens / 10_000))
    return credits
```
