Memory Cleanup Verification

Heap snapshot comparison to verify cache clearing on logout

Prerequisites

Required Browser
Use Chrome or Edge (Chromium-based) for Memory Profiler support
  1. Open application in Incognito/Private window (clean state)
  2. Open DevTools (F12 or Cmd/Ctrl + Shift + I)
  3. Navigate to Memory tab in DevTools
  4. Ensure you have a test account with data (projects, templates)

Testing Protocol

1
Baseline Snapshot (Before Login)
  1. Navigate to login page
  2. In Memory tab, click "Take heap snapshot"
  3. Label as baseline
  4. Note the heap size in the snapshot list
2
Load User Data (After Login)
  1. Log in with test credentials
  2. Navigate through the app:
    • Visit dashboard (loads user stats)
    • Visit templates gallery (loads template list)
    • Visit projects (loads project list)
    • Open 2-3 projects (loads project details)
  3. Wait 3 seconds for all data to load
  4. Take heap snapshot, label as logged-in
3
Perform Logout
  1. Click logout button
  2. Wait for redirect to login page (automatic)
  3. Wait 2 seconds for cleanup to complete
4
Verify Cleanup (After Logout)
  1. Take heap snapshot, label as after-logout
  2. In Memory tab, click "after-logout" snapshot
  3. In dropdown at top, select "Comparison" view
  4. Choose "baseline" as comparison target
5
Analyze Results
Expected Result: - Heap size: after-logout ≈ baseline (within 10%) - Deleted objects: React Query cache entries - Deleted objects: Zustand store state - Retained size: minimal increase from baseline
Success Criteria
Memory increase < 5MB after logout (compared to baseline)

React Query Cache Verification

To verify React Query cache is cleared, run this in DevTools Console:

// BEFORE logout (should have data) window.__REACT_QUERY_DEVTOOLS__ = true queryClient = window.__REACT_QUERY_CLIENT__ console.log('Queries count:', queryClient.getQueryCache().getAll().length) console.log('Queries:', queryClient.getQueryCache().getAll().map(q => ({ queryKey: q.queryKey, state: q.state.status, dataUpdatedAt: new Date(q.state.dataUpdatedAt).toISOString() }))) // AFTER logout (should be empty) console.log('Queries count:', queryClient.getQueryCache().getAll().length) // Expected: 0
Note
If you see error "queryClient is not defined", React Query client is not exposed to window. Proceed with heap snapshot analysis instead.

Automated Test Script (Optional)

For repetitive testing, use Playwright script:

// frontend/e2e/memory-cleanup.spec.ts import { test, expect } from '@playwright/test' test('cache cleared on logout - memory verification', async ({ page, context }) => { // Enable memory tracking const client = await context.newCDPSession(page) // Baseline snapshot await page.goto('/login') const baseline = await client.send('HeapProfiler.takeHeapSnapshot') // Login and load data await page.fill('[name="email"]', 'test@viably.io') await page.fill('[name="password"]', 'password123') await page.click('button[type="submit"]') await page.waitForURL('/dashboard') await page.goto('/templates') await page.goto('/projects') await page.waitForTimeout(3000) // Load data const loggedIn = await client.send('HeapProfiler.takeHeapSnapshot') // Logout await page.click('[data-testid="logout-button"]') await page.waitForURL('/login') await page.waitForTimeout(2000) // Cleanup const afterLogout = await client.send('HeapProfiler.takeHeapSnapshot') // Assert memory released const memoryIncrease = afterLogout.nodes.length - baseline.nodes.length expect(memoryIncrease).toBeLessThan(1000) // Fewer than 1000 extra objects })

Troubleshooting

Issue: Memory not released after logout
Possible causes:
  1. clearAllCaches() not called in logout flow
  2. Zustand stores not reset (missing reset() method)
  3. WebSocket connections not closed
  4. Event listeners not removed
Debug steps:
