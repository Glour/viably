## Step 1: Sign Up & Get Credits

First, you need to create your Viably account and claim your free credits.

### Create Your Account

1. Go to [viably.dev](https://viably.dev)
2. Click **Sign Up** in the top right corner
3. Enter your email and create a password
4. Verify your email address

![Sign up process](/docs/quickstart/step-1-signup.png)

### Claim Your Free Credits

When you sign up, you automatically receive **100 free credits** to start building. These credits let you generate and test your bots without entering payment information.

> **Daily Bonus**: Come back every day to claim an additional **10 free credits**. Building habits pays off!

### Understanding Credits

Each bot generation costs **10 credits**. With your starting balance of 100 credits, you can:

- Generate 10 different bots
- Experiment with various templates
- Test different configurations

**Next Step**: Now that you have credits, let's choose a template for your first bot.

## Step 3: Customize Your Bot

Now comes the fun part: making your bot uniquely yours. You'll define how your bot talks, what commands it understands, and how it responds to users.

### Open the Editor

1. Click **Use Template** on your chosen template
2. You'll see the bot customization interface with three main sections:
   - **Configuration** (left panel): Bot settings and metadata
   - **Code Editor** (center): Your bot's logic and responses
   - **Preview** (right panel): Test your bot in real-time

![Bot customization interface](/docs/quickstart/step-3-customize.png)

### Configure Basic Settings

In the left panel, fill in:

```typescript
{
  "name": "MyDiscordBot",
  "platform": "discord",
  "personality": "friendly and helpful",
  "language": "en",
  "responseTime": "fast"
}
```

**Name**: Choose a memorable name for your bot (e.g., "SupportBot", "GameMaster", "TeamHelper")

**Personality**: Describe how your bot should talk:
- "friendly and helpful" - warm, approachable tone
- "professional and concise" - business-like, direct
- "playful and quirky" - fun, uses emojis and jokes
- "technical and precise" - detailed, accurate responses

### Customize Bot Behavior

The Monaco Editor in the center lets you define your bot's commands and responses. Here's an example configuration:

```python
# Define bot commands
commands = {
    "hello": "Hi there! I'm {bot_name}, your AI assistant. How can I help you today?",
    "help": "I can assist you with questions, provide information, or just chat. Try asking me anything!",
    "about": "I'm an AI-powered bot created with Viably. I'm here to make your life easier!"
}

# Configure response style
response_style = {
    "greeting": "friendly",
    "error_handling": "helpful",
    "fallback": "I'm not sure I understand. Could you rephrase that?"
}
```

### Key Areas to Customize

**Commands**: What slash commands or keywords trigger specific responses
**Greetings**: How your bot introduces itself
**Error Messages**: What happens when users ask something unexpected
**Personality Traits**: Tone, formality level, use of emojis

> **Pro Tip**: Keep your initial bot simple. You can always add more complexity later. Start with 3-5 core commands and expand from there.

### Test as You Go

Use the Preview panel on the right to test your bot:

1. Type a message in the preview chat
2. See how your bot responds
3. Adjust the configuration if needed
4. Repeat until you're happy

**Next Step**: Your bot is configured. Let's generate the production-ready code.

## Step 4: Generate with AI

With your bot configured, it's time to let Viably's AI generate the production-ready code, configuration files, and deployment setup.

### Start Generation

1. Click the big green **Generate** button at the top right
2. Confirm that you want to use **10 credits** for this generation
3. Watch the magic happen

![Generation progress screen](/docs/quickstart/step-4-generate.png)

### What's Happening Behind the Scenes

When you click Generate, Viably's AI:

1. **Analyzes** your configuration and requirements
2. **Generates** optimized bot code for your platform
3. **Creates** configuration files (environment variables, API setup)
4. **Prepares** deployment scripts and infrastructure code
5. **Validates** everything works together

This entire process takes **30-60 seconds** and costs **10 credits**.

### Real-Time Progress Updates

You'll see live updates via WebSocket connection:

```bash
[1/5] Analyzing configuration... ✓
[2/5] Generating bot logic... ✓
[3/5] Creating API handlers... ✓
[4/5] Setting up deployment... ✓
[5/5] Running final validation... ✓

Generation complete! Your bot is ready to deploy.
```

### What You Get

After generation completes, you'll have:

- **Source Code**: Complete, production-ready bot implementation
- **Configuration Files**: `.env.example`, `config.json`, API keys setup
- **Deployment Scripts**: One-click deployment to Viably Cloud
- **Documentation**: README with setup instructions

### Review Generated Code

Before deploying, you can:

- Browse the generated files in the code viewer
- Download the complete project as a `.zip` file
- Read the auto-generated README for customization tips

> **Note**: Each generation is unique. If you're not satisfied with the result, you can regenerate with different settings. Each regeneration costs another 10 credits.

**Next Step**: Your bot is generated and ready. Let's deploy it to the cloud.

## Step 5: Deploy Your Bot

The final step: deploy your bot to production and make it live for the world to use.

### One-Click Deployment

1. Click the **Deploy** button
2. Viably will automatically:
   - Build a Docker container for your bot
   - Deploy it to our servers
   - Set up environment variables
   - Configure SSL via Certbot
   - Start your bot

![Deployment success screen](/docs/quickstart/step-5-deploy.png)

### Deployment Progress

Watch your bot go live in real-time:

```bash
Deploying to Viably Cloud...
→ Building container... ✓
→ Pushing to server... ✓
→ Configuring Nginx... ✓
→ Provisioning SSL... ✓
→ Bot is now LIVE! 🎉
```

### Get Your Bot URL

Once deployed, you'll receive:

- **Bot URL**: Your bot's public endpoint (e.g., `https://my-bot.viably.dev`)
- **Dashboard**: Manage your bot from the Viably dashboard
- **Logs Link**: View real-time deployment logs and debugging info

### Connect Your Bot

Depending on your platform:

**Discord**:
1. Copy your bot's URL
2. Go to Discord Developer Portal
3. Add the URL as your bot's endpoint
4. Invite your bot to a server

**Telegram**:
1. Copy your bot token
2. Set the webhook URL to your Viably endpoint
3. Your bot is instantly live

**Slack**:
1. Go to Slack API Dashboard
2. Set your bot's Request URL to the Viably endpoint
3. Install the bot to your workspace

**WhatsApp**:
1. Configure the webhook in Meta Developer Console
2. Verify the webhook token
3. Your bot is ready to receive messages

### Verify It's Working

Test your bot:

1. Open your messaging platform (Discord, Telegram, etc.)
2. Send a message to your bot
3. You should receive a response within 1-2 seconds

> **Troubleshooting**: If your bot doesn't respond, check the deployment logs in the Viably dashboard. Most issues are due to incorrect API tokens or webhook URLs.

**Congratulations!** Your AI bot is now live and responding to users.

## Common Questions

### How much do bot generations cost?

Each generation costs **10 credits**. You get **100 free credits** on signup, plus **10 daily credits** for logging in.

### Can I edit my bot after deployment?

Yes! Return to your Viably dashboard, make changes, regenerate (10 credits), and redeploy. Viably will automatically update your live bot.

### What if I run out of credits?

You can purchase additional credits in your account settings, or wait for daily bonuses to accumulate.

### Can I use my own hosting instead of Viably Cloud?

Absolutely. Download your generated bot code and deploy it anywhere: AWS, Google Cloud, DigitalOcean, or your own servers.

### Is my bot code open source?

Your generated code is **yours to keep**. You can modify it, redistribute it, or use it commercially without restrictions.
