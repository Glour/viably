## 🚀 Создай бота за 5 минут

Viably позволяет создавать и запускать ботов без написания кода. AI сгенерирует всё за тебя — нужно только описать, что хочешь получить.

**Засекай время!** Через 5 минут у тебя будет работающий бот в Telegram.

---

## Шаг 1. Регистрация (30 секунд)

1. Перейди на [viably.dev](https://viably.dev)
2. Нажми **«Регистрация»**
3. Выбери способ входа:
   - **GitHub** — в один клик
   - **Google** — быстро и просто
   - **Email** — классический способ

После входа ты получишь:
- ✅ **10 бесплатных кредитов** — хватит на несколько проектов
- ✅ Доступ к дашборду и всем шаблонам
- ✅ Возможность деплоя на домены `.viably.app`

---

## Шаг 2. Создай проект (1 минута)

### Вариант А: Выбери готовый шаблон

1. На дашборде нажми **«Новый проект»**
2. Увидишь список шаблонов:
   - 🛒 **Shop Bot** — магазин в Telegram
   - ❓ **FAQ Bot** — автоответчик
   - 📄 **Landing Page** — продающий сайт
   - 📝 **Blog** — платформа для контента
   - 💼 **Portfolio** — сайт-портфолио

3. Выбери нужный (например, **Shop Bot**)

### Вариант Б: Опиши своими словами

Если ни один шаблон не подходит — опиши проект сам:

**Примеры промптов:**

```
Telegram-бот для записи на стрижку с выбором мастера и времени
```

```
Сайт-портфолио для фотографа с галереей работ и формой заказа
```

```
FAQ-бот для онлайн-школы программирования с категориями вопросов
```

**Совет:** Чем подробнее описание — тем точнее результат!

---

## Шаг 3. Настрой детали (1 минута)

После выбора шаблона укажи:

### Для ботов:
- **Название** (например, "PizzaExpress Бот")
- **Категории товаров/вопросов** (если применимо)
- **Особенности** (оплата, доставка, уведомления и т.д.)

### Для сайтов:
- **Название проекта** (например, "Моё портфолио")
- **Цветовая схема** (синий/белый, тёмная тема и т.д.)
- **Секции** (о себе, контакты, галерея)

**Пример заполнения для Shop Bot:**

```
Название: Доставка пиццы "Мамма Мия"
Категории: Пицца, Закуски, Напитки, Десерты
Оплата: наличные или картой курьеру
Доставка: по Москве в пределах МКАД
Дополнительно: уведомления администратору в Telegram
```

---

## Шаг 4. Генерация кода (1 минута)

1. Нажми **«Сгенерировать»**
2. AI начнёт создавать проект:
   - Структуру файлов
   - Код на Node.js/Python/PHP (зависит от шаблона)
   - База данных (если нужна)
   - Конфигурационные файлы

**Прогресс:**
- ⏱ Простой бот: 30–45 секунд
- ⏱ Сложный проект: 1–2 минуты

Ты увидишь:
- 📂 **Список файлов** (слева)
- 📝 **Код каждого файла** (по клику)
- 👁 **Превью** (справа, если это сайт)

---

## Шаг 5. Просмотри код (30 секунд)

Сгенерированный код можно:
- **Просмотреть** — кликни на файл, чтобы увидеть содержимое
- **Отредактировать** — внеси изменения прямо в редакторе
- **Попросить доработать AI** — нажми "Edit with AI" и опиши что изменить

**Пример доработки:**

```
Добавь категорию "Комбо-наборы" и сделай кнопки зелёными
```

---

## Шаг 6. Деплой (2 минуты)

### Для Telegram-ботов:

1. **Создай бота через [@BotFather](https://t.me/BotFather):**
   - Открой Telegram
   - Найди бота [@BotFather](https://t.me/BotFather)
   - Напиши `/newbot`
   - Укажи название и username (например, `pizzaexpress_bot`)
   - Скопируй полученный **токен** (выглядит так: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

2. **Вернись в Viably:**
   - Вставь токен в поле "Telegram Bot Token"
   - (Опционально) Укажи другие переменные окружения (API-ключи, настройки БД)

3. **Нажми «Деплой»:**
   - Процесс займёт 30–60 секунд
   - Увидишь логи развёртывания

4. **Готово!**
   - Статус изменится на **"Running"** (зелёный)
   - Открой бота в Telegram и напиши `/start` — он ответит!

### Для сайтов:

1. **Нажми «Деплой»** — всё!
2. Получи публичную ссылку (например, `https://my-portfolio.viably.app`)
3. (Опционально) Подключи свой домен в настройках

## 🎉 Готово! Что дальше?

Твой проект запущен и работает! Теперь ты можешь:

### Для ботов:

## 🆘 Что-то не работает?

### Бот не отвечает?
- Проверь токен (скопирован полностью?)
- Проверь статус деплоя (должен быть "Running")
- Посмотри логи (может быть ошибка)

### Сайт не открывается?
- Подожди 1–2 минуты (DNS может обновляться)
- Проверь логи деплоя на ошибки
- Попробуй "Redeploy"

**Не нашёл решение?** Загляни в [Troubleshooting](/docs/troubleshooting) — там ответы на частые проблемы.
