## Overview

This guide covers everything you need to know about installing and setting up Viably for local development or production deployment.

## System Requirements

Before installing Viably, ensure your system meets these requirements:

### Minimum Requirements

- **Node.js**: Version 18.0 or higher
- **Python**: Version 3.11 or higher
- **PostgreSQL**: Version 15 or higher
- **Redis**: Version 7.0 or higher (for background jobs)
- **RAM**: 4GB minimum, 8GB recommended
- **Storage**: 10GB free space

### Recommended Requirements

- **Node.js**: Version 20.x LTS
- **Python**: Version 3.12
- **PostgreSQL**: Version 16
- **RAM**: 16GB
- **Storage**: 50GB SSD

## Installation Methods

Choose the installation method that best suits your needs:

### 1. Quick Start (Recommended)

The fastest way to get started with Viably:

```bash
# Install Viably CLI globally
npm install -g viably-cli

# Create a new project
viably create my-bot-project

# Navigate to project
cd my-bot-project

# Start development server
viably dev
```

Your Viably instance will be available at `http://localhost:3000`.

### 2. Docker Installation

For containerized deployment:

```bash
# Clone the repository
git clone https://github.com/viably/viably.git
cd viably

# Start with Docker Compose
docker-compose up -d

# Check status
docker-compose ps
```

Services will be available at:
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **Database**: localhost:5432

### 3. Manual Installation

For complete control over the setup:

#### Backend Setup

```bash
# Clone repository
git clone https://github.com/viably/viably.git
cd viably/backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Set up environment variables
cp .env.example .env
# Edit .env with your configuration

# Run migrations
alembic upgrade head

# Start backend server
uvicorn app.main:app --reload
```

#### Frontend Setup

```bash
# Navigate to frontend directory
cd ../frontend

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your configuration

# Start development server
npm run dev
```

## Configuration

### Environment Variables

Create a `.env` file with these required variables:

#### Backend (.env)

```bash
# Database
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/viably
DATABASE_ECHO=false

# Redis
REDIS_URL=redis://localhost:6379/0

# Security
SECRET_KEY=your-secret-key-here
JWT_SECRET=your-jwt-secret-here
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Anthropic API
ANTHROPIC_API_KEY=your-anthropic-api-key

# Sentry (optional)
SENTRY_DSN=your-sentry-dsn

# PostHog (optional)
POSTHOG_API_KEY=your-posthog-key
```

#### Frontend (.env.local)

```bash
# API URLs
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000

# Sentry
SENTRY_ORG=your-org
SENTRY_PROJECT=your-project
SENTRY_AUTH_TOKEN=your-auth-token

# PostHog
NEXT_PUBLIC_POSTHOG_KEY=your-posthog-key
NEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com
```

### Database Setup

Initialize your PostgreSQL database:

```sql
-- Create database
CREATE DATABASE viably;

-- Create user
CREATE USER viably_user WITH PASSWORD 'your_password';

-- Grant privileges
GRANT ALL PRIVILEGES ON DATABASE viably TO viably_user;
```

Then run migrations:

```bash
cd backend
alembic upgrade head
```

## Verification

Verify your installation is working correctly:

### 1. Check Backend Health

```bash
curl http://localhost:8000/health
```

Expected response:
```json
{
  "status": "healthy",
  "database": "connected",
  "redis": "connected"
}
```

### 2. Check Frontend

Open your browser and navigate to `http://localhost:3000`. You should see the Viably landing page.

### 3. Run Tests

```bash
# Backend tests
cd backend
pytest

# Frontend tests
cd frontend
npm run test
```

## Production Deployment

For production deployment, we recommend:

### Option 1: Railway (Easiest)

1. Fork the Viably repository
2. Sign up at [Railway.app](https://railway.app)
3. Click "New Project" → "Deploy from GitHub"
4. Select your forked repository
5. Configure environment variables
6. Deploy!

### Option 2: Vercel + Railway

**Frontend (Vercel):**
1. Connect your GitHub repository to Vercel
2. Configure environment variables
3. Deploy

**Backend (Railway):**
1. Deploy backend separately on Railway
2. Add PostgreSQL and Redis services
3. Configure environment variables

### Option 3: Self-Hosted

Use the provided Docker Compose configuration:

```bash
# Production docker-compose
docker-compose -f docker-compose.prod.yml up -d
```

## Troubleshooting

### Port Already in Use

If port 3000 or 8000 is already in use:

```bash
# Kill process on port 3000 (frontend)
lsof -ti:3000 | xargs kill -9

# Kill process on port 8000 (backend)
lsof -ti:8000 | xargs kill -9
```

### Database Connection Failed

Check that PostgreSQL is running:

```bash
# macOS
brew services start postgresql

# Linux
sudo systemctl start postgresql

# Windows
net start postgresql-x64-15
```

### Redis Connection Failed

Start Redis server:

```bash
# macOS
brew services start redis

# Linux
sudo systemctl start redis

# Windows
redis-server
```

### Module Not Found Errors

Reinstall dependencies:

```bash
# Backend
cd backend
pip install -r requirements.txt --force-reinstall

# Frontend
cd frontend
rm -rf node_modules package-lock.json
npm install
```

## Updating Viably

Keep your Viably installation up to date:

```bash
# Pull latest changes
git pull origin main

# Update backend dependencies
cd backend
pip install -r requirements.txt

# Run migrations
alembic upgrade head

# Update frontend dependencies
cd ../frontend
npm install

# Rebuild
npm run build
```
