## Getting Started

### What is Viably?

Viably is an AI-powered platform that generates production-ready bots and API services from templates. You customize a template with your requirements, and our AI generates complete, deployable code in under 60 seconds. Think of it as a technical co-founder that handles infrastructure, security, and best practices while you focus on your bot's personality and features.

### How do I create my first bot?

Creating your first bot takes less than 10 minutes:

1. **Sign up** at viably.dev and claim your 100 free credits
2. **Choose a template** from our gallery (Discord, Telegram, Slack, WhatsApp, or Custom)
3. **Customize** your bot's personality, commands, and behavior in the editor
4. **Generate** with AI (costs 10 credits, takes 30-60 seconds)
5. **Deploy** to Railway with one click, or download and self-host

Check out our [Quick Start Guide](/docs/quickstart) for detailed step-by-step instructions with screenshots.

### Do I need coding skills to use Viably?

No coding is required for basic bot creation. Our visual editor lets you configure your bot's personality, commands, and responses through simple forms. However, coding skills unlock advanced features:

- **No Code**: Perfect for simple bots with predefined commands
- **Basic Coding**: Customize responses, add API integrations, modify bot logic
- **Advanced Coding**: Build custom workflows, multi-platform bots, complex integrations

Our generated code is clean, well-commented Python or JavaScript, making it great for learning if you're new to programming.

### Which platforms are supported?

Viably currently supports five major platforms:

- **Discord**: Gaming communities, social servers, moderation bots
- **Telegram**: Personal assistants, notifications, customer support
- **Slack**: Workplace automation, team productivity, integrations
- **WhatsApp**: Business messaging, customer engagement, support
- **Custom**: API-based bots, multi-platform, webhooks, any custom integration

Each template is optimized for its platform's unique features and limitations. See our [Template Guide](/docs/templates/guide) for a detailed comparison.

### How long does it take to generate a bot?

Bot generation takes **30-60 seconds** on average. During this time, our AI:

1. Analyzes your configuration and requirements
2. Generates optimized, platform-specific code
3. Creates configuration files and environment setup
4. Prepares deployment scripts
5. Validates everything works together

You'll see real-time progress updates via WebSocket as each step completes.

### Can I test my bot before deploying?

Yes! After generation, you can:

- **Preview the code** in our built-in code viewer
- **Download as .zip** and run locally with test accounts
- **Deploy to Railway** free tier for live testing (within $5/month credit)

We recommend testing with a small group of users before launching publicly. Most platforms offer test environments (Discord test servers, Telegram test bots, etc.).

## Templates

### What templates are available?

Viably offers five production-ready templates:

1. **Discord Bot**: Slash commands, embeds, roles, moderation (beginner-friendly)
2. **Telegram Bot**: Commands, inline keyboards, channels, file sharing (beginner-friendly)
3. **Slack Bot**: Slash commands, workflows, modals, enterprise features (intermediate)
4. **WhatsApp Bot**: Message templates, media, business API (intermediate)
5. **Custom Bot**: API endpoints, webhooks, multi-platform (advanced)

Each template includes best practices, error handling, rate limiting, logging, and one-click deployment configuration. See our [Template Gallery](/templates) for live demos.

### Can I customize templates?

Absolutely! Templates are starting points, not limitations. You can customize:

**Configuration Level** (no coding):
- Bot personality (friendly, professional, technical, playful)
- Commands and trigger keywords
- Response patterns and fallbacks
- Language and tone

**Code Level** (advanced):
- Add API integrations (weather, news, databases)
- Implement custom workflows and state machines
- Connect to external services (Stripe, Shopify, etc.)
- Modify response logic and AI prompts

Generated code is yours to modify freely. You can even combine multiple templates or build something completely custom.

### Can I switch templates after generation?

Yes, but you'll need to regenerate your bot (another 10 credits). Here's the process:

1. Export your current bot's configuration
2. Choose a new template
3. Import your configuration (commands, personality, etc.)
4. Adjust platform-specific features (e.g., Discord embeds → Telegram keyboards)
5. Regenerate with the new template (10 credits)
6. Test thoroughly before switching users

**What Transfers**: Bot personality, command logic, API integrations, response patterns
**What Needs Rewriting**: Platform-specific UI (embeds, keyboards, modals, buttons)

See our [Migration Guide](/docs/templates/guide#migration-guide) for detailed steps.

### What's the difference between templates?

Templates differ by platform, complexity, and use case:

**Discord vs Telegram**:
- Discord: Richer UI (embeds, colors, images), gaming focus, voice channels
- Telegram: Faster, simpler, inline keyboards, better for notifications

**Slack vs WhatsApp**:
- Slack: Workplace automation, enterprise features, OAuth flows
- WhatsApp: Consumer-facing, message templates, Meta Business approval required

**Custom vs Platform Templates**:
- Custom: Platform-agnostic, full control, requires more setup
- Platform Templates: Optimized for specific platform, faster to deploy

See our [Template Comparison Table](/docs/templates/guide#template-comparison-table) for side-by-side feature comparison.

### Can I use multiple templates for one project?

Yes, through two approaches:

**Approach 1: Shared Backend**
- Use Custom template to create a shared API
- Deploy separate platform-specific bots (Discord, Telegram, etc.)
- All bots call the same backend for logic

**Approach 2: Adapter Pattern**
- Generate Custom template with platform adapters
- Route messages based on source platform
- Share AI logic, customize responses per platform

Most users start with one platform and expand later. Multi-platform adds complexity but maximizes reach.

### How often are templates updated?

Templates are updated quarterly (every 3 months) to:

- Support new platform features (Discord API updates, Slack modals v2)
- Fix security vulnerabilities
- Improve performance and best practices
- Add community-requested features

**Your Bots**: Template updates don't affect already-generated bots. You can:
- Continue using your current bot (no changes needed)
- Regenerate to get latest updates (10 credits)
- Manually merge changes if you've heavily customized

We notify users of major template updates via email and Discord announcements.

### How do I deploy to my own server?

To self-host your bot:

1. **Download** your generated bot as .zip after generation
2. **Extract** to your server or local machine
3. **Install Dependencies**:
   ```bash
   # Python bots
   pip install -r requirements.txt

   # JavaScript bots
   npm install
   ```
4. **Configure Environment**:
   ```bash
   cp .env.example .env
   # Edit .env with your API keys
   ```
5. **Run Locally** (for testing):
   ```bash
   # Python
   python main.py

   # JavaScript
   npm start
   ```
6. **Deploy to Production**:
   ```bash
   # Using Docker
   docker build -t my-bot .
   docker run -d -p 8000:8000 --env-file .env my-bot

   # Using systemd (Linux)
   sudo systemctl start my-bot
   ```

See platform-specific deployment guides for AWS, GCP, DigitalOcean, and more.

### Is my bot scalable?

Yes, generated bots are designed for scalability:

**Built-In Features**:
- Async/await for non-blocking I/O (handles thousands of concurrent users)
- Connection pooling for database queries
- Rate limiting to prevent abuse
- Stateless design for horizontal scaling

**Scaling Strategies**:
- **Vertical Scaling**: Increase server resources (RAM, CPU) for single instance
- **Horizontal Scaling**: Deploy multiple instances behind load balancer
- **Database Scaling**: Use PostgreSQL with read replicas or Redis for caching

**Typical Performance**:
- Small bot (< 1000 users): Single Railway instance ($5-10/month)
- Medium bot (1K-10K users): 2-3 instances with load balancer ($20-50/month)
- Large bot (10K-100K users): Auto-scaling cluster with Redis cache ($100-500/month)

Our generated code is production-tested for bots with 100K+ daily active users.

### Can I update my bot after deployment?

Yes, you can update deployed bots anytime:

**For Configuration Changes**:
1. Modify settings in Viably editor
2. Regenerate (10 credits)

**For Code Changes**:

**Zero-Downtime Updates**:

4. **Support**: Contact support@viably.dev with your generation ID for help

**Common Causes**:

## Troubleshooting

### My bot isn't responding. What should I check?

Common issues and solutions:

**1. Check Deployment Status**:
- Railway: Go to Railway dashboard, verify service is "Running"
- Self-hosted: SSH to server, check process: `ps aux | grep bot`

**2. Verify API Keys**:
- Discord: Check bot token in .env matches Discord Developer Portal
- Telegram: Verify bot token with BotFather
- API keys must be active and have correct permissions

**3. Check Logs**:
- Railway: View logs in Railway dashboard
- Self-hosted: `tail -f /var/log/my-bot.log`
- Look for error messages: "Unauthorized", "Rate limited", "Connection refused"

**4. Test Connectivity**:
- Verify webhook URL is accessible: `curl https://your-bot.railway.app/webhook`
- Check firewall rules allow incoming traffic on port 8000

**5. Platform-Specific**:
- Discord: Bot must be invited to server with correct permissions
- Telegram: Webhook must be set correctly (`setWebhook` command)
- Slack: Request URL must be verified in Slack App settings

Still stuck? Join our [Discord](https://discord.gg/viably) #help channel with logs and error messages.

### Generation is taking too long. Is something wrong?

Normal generation takes 30-60 seconds. If it exceeds 2 minutes:

1. **Check Network**: Slow internet may delay upload of configuration
2. **Try Again**: Click "Cancel" and retry generation
3. **Clear Cache**: Log out and log back in
4. **Contact Support**: If issue persists, email support@viably.dev with generation ID

Our AI infrastructure handles thousands of concurrent generations, so delays are rare.

### I can't deploy to Railway. What's wrong?

Common Railway deployment issues:

**Error: "Unauthorized"**:
- Sign in to Railway via GitHub
- Authorize Viably to deploy on your behalf in Railway settings

**Error: "Plan limit exceeded"**:
- Railway free tier has limits (2 active projects)
- Delete unused projects or upgrade to Railway Pro

**Error: "Build failed"**:
- Check Railway logs for specific error
- Often caused by missing environment variables
- Verify .env.example includes all required keys

**Error: "Health check failed"**:
- Your bot isn't responding on the expected port (usually 8000)
- Check `PORT` environment variable in Railway settings

For Railway-specific issues, see [Railway Troubleshooting Guide](/docs/deployment/railway#troubleshooting).

### My credits aren't showing up after purchase.

If your credits don't appear immediately after purchase:

1. **Refresh Page**: Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
2. **Check Email**: Verify payment confirmation email was received
3. **Wait 5 Minutes**: Stripe payments can take 1-5 minutes to process
4. **Check Payment Status**: Go to Settings > Billing > Payment History
5. **Contact Support**: If credits still missing after 10 minutes, email support@viably.dev with transaction ID

Payments are processed securely via Stripe. We do not store credit card information.
