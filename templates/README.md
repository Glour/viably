Готовые шаблоны для быстрого старта ваших проектов. Каждый шаблон включает:

## 📦 Доступные шаблоны

### 🤖 Telegram Боты

#### 1. Shop Bot
**Магазин в Telegram с корзиной и оформлением заказов**

- 🛍 Каталог товаров с описаниями и ценами
- 🛒 Корзина покупок
- ✅ Оформление заказа с контактными данными
- 👨‍💼 Уведомления админу о новых заказах
- 🎨 Удобный интерфейс на inline-кнопках

📁 [Код](./shop-bot/) | 📖 [README](./shop-bot/README.md)

**Быстрый старт:**
```bash
cd shop-bot
pip install -r requirements.txt
cp .env.example .env
# Настройте .env
python bot.py
```

## 🚀 Как использовать

### 1. Скачайте нужный шаблон

```bash
git clone https://github.com/Glour/viably.git
cd viably/templates/[название-шаблона]
```

### 2. Следуйте инструкциям в README

Каждый шаблон имеет подробный README с:
- Инструкциями по установке
- Настройке окружения
- Кастомизации
- Деплою

### 3. Настройте под себя

- Отредактируйте код под ваши нужды
- Добавьте свой контент
- Настройте переменные окружения

### 4. Задеплойте

- **Telegram боты**: простой VPS с Python
- **Next.js проекты**: Vercel (1 клик), Netlify, или Docker

## 📚 Технологии

### Telegram Боты
- **Python 3.11+**
- **aiogram 3.4** - современный фреймворк для Telegram Bot API
- **FSM** - управление состояниями для сложных сценариев

### Веб-проекты
- **Next.js 15** - React фреймворк с App Router
- **React 19** - последняя версия
- **TypeScript** - типобезопасность
- **Tailwind CSS 3** - utility-first стили
