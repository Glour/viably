# Getting Started

This blog template makes it easy to write and publish articles using MDX.

## Creating a New Post

1. Create a new `.mdx` file in the `posts/` directory
2. Add frontmatter with title, date, excerpt, and tags
3. Write your content using Markdown
4. Build and deploy!

## Frontmatter Example

```yaml
---
title: 'Your Post Title'
date: '2024-01-20'
excerpt: 'A short description'
tags: ['tag1', 'tag2']
---
```

## MDX Features

You can use all standard Markdown features plus React components!

**Bold text**, *italic text*, and [links](https://example.com).

Happy blogging! 🚀
