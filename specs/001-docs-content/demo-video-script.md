# Demo Video Script: Viably Platform Walkthrough

**Duration**: 90-120 seconds
**Format**: Screen recording with voiceover
**Target Audience**: First-time visitors, potential users
**Platform**: YouTube embed on landing page and docs

---

## Script Overview

**Hook**: Show the power of AI-driven bot creation in under 2 minutes
**Journey**: Registration → Template Selection → Configuration → AI Generation → Deploy
**Goal**: Demonstrate complete workflow from signup to working bot

---

## Production Checklist

### Pre-Recording
- [ ] Set up clean test account (test@viably.dev)
- [ ] Create sample bot template data (Sushi Bot)
- [ ] Prepare Telegram bot demo (@sushi_delivery_bot)
- [ ] Clear browser cache/cookies
- [ ] Set browser to 1920x1080 window
- [ ] Disable browser notifications
- [ ] Use incognito mode (no extensions)

### Recording Setup
- [ ] Screen recorder: OBS Studio or ScreenFlow
- [ ] Resolution: 1920x1080 @ 60fps
- [ ] Audio: High-quality microphone (no background noise)
- [ ] Lighting: Good lighting for face cam (if included)
- [ ] Background music: Royalty-free track (Epidemic Sound or Artlist)

### Post-Production
- [ ] Trim dead air and pauses
- [ ] Speed up slow sections (form filling, typing)
- [ ] Add text overlays at keyframes
- [ ] Mix voiceover with background music (music at -20dB)
- [ ] Color correction (ensure consistent brightness)
- [ ] Add smooth transitions between scenes
- [ ] Export: H.264, 1920x1080, 30fps, 8Mbps bitrate

### YouTube Upload
- [ ] Title: "Viably Demo: Build Telegram Bots in 60 Seconds with AI"
- [ ] Description: Link to viably.dev, feature list, timestamps
- [ ] Tags: telegram bot, ai, no-code, viably, bot builder, automation
- [ ] Thumbnail: Custom thumbnail (1280x720) with "60 SECONDS" text
- [ ] Chapters: Add timestamps for each scene
- [ ] Subtitles: Upload Russian + English .srt files
- [ ] Cards: Add end screen with CTA link
- [ ] Visibility: Public (or Unlisted for pre-launch)
