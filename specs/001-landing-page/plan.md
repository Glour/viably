## Summary

Публичная landing page (viably.dev) с wow-эффектами: Hero секция с glow orbs и анимированной демо-карточкой, How It Works (3 шага), Templates Preview (6 карточек), Pricing (3 плана с monthly/yearly toggle), Footer. Использует Next.js 16 с Turbopack, Motion для анимаций, react-type-animation для typing эффекта. Все данные статичные (TypeScript constants), no database needed. Performance target: LCP < 2.5s, 60 FPS animations, responsive 320px-2560px.

## Technical Context

**Language/Version**: TypeScript 5.x, React 19.2.3, Node.js 18+
**Primary Dependencies**:
- Next.js 16.1.6 (Turbopack bundler, React Compiler)
- Motion (latest) - scroll-triggered animations, stagger effects, gestures
- react-type-animation (latest) - typewriter effects
- Tailwind CSS v4 - styling
- lucide-react - icons
- Zod - data validation

**Storage**:
- In-memory (TypeScript constants for templates/pricing data)
- localStorage (pricing period preference only)
- No database required

**Testing**: Vitest (already in project)

**Target Platform**: Web (modern browsers: Chrome, Firefox, Safari, Edge)

**Project Type**: Web (Next.js frontend application)

**Performance Goals**:
- 60 FPS для всех анимаций (scroll, hover, transitions)
- LCP < 2.5s на 3G соединении
- First Contentful Paint < 1.5s
- Lighthouse score > 90

**Constraints**:
- Bundle size < 200KB gzipped
- CLS < 0.1 (no layout shifts)
- INP < 100ms (smooth interactions)
- Mobile-first responsive (320px minimum width)
- Graceful degradation (JavaScript disabled)
- Accessibility: WCAG 2.1 AA, prefers-reduced-motion support

**Scale/Scope**:
- 1 page (landing page at `/`)
- 7 components (Nav, Hero, HowItWorks, TemplatesPreview, Pricing, Footer + demo card)
- 6 template cards (static data)
- 3 pricing plans (static data)
- Estimated: 2 days development time

## Risk Mitigation

### Technical Risks

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Animations cause jank on low-end devices | Medium | High | Use prefers-reduced-motion, GPU transforms only, test on throttled CPU |
| Bundle size exceeds budget (>200KB) | Low | Medium | Dynamic imports for heavy components, tree-shaking, bundle analyzer |
| Glow orbs don't work on Safari | Low | Low | Fallback to static gradients, test on Safari early |
| localStorage not available (privacy mode) | Low | Low | Graceful fallback to default "monthly" |
| Template/Pricing data structure changes | Low | Medium | Zod validation will catch mismatches, types ensure compile-time safety |

| Risk | Probability | Impact | Mitigation |
